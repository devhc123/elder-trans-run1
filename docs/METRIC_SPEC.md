# KPI-1 适老化转译可读性达标率 —— 指标规格

> 实现：`metrics/readability.py`（确定性，无 LLM 调用）
> 词表构建：`pipeline/build_lexicon.py`
> 测试：`tests/`（72 个：单元 / 分词性质 / code review 逐条回归）
> 关联票据：`.scratch/elder-trans-harness/issues/02-readability-scorer.md`

## 1. 定义

对转译后文本 T：

1. 掩去完整日期与钟点时间（报告签发日期之类不属于转译文本的可读性）。
2. 做**术语感知分词**（见 §4.1）得到词序列。
3. 取**计分词** W′：含汉字的词，或以拉丁字母开头的 token（HbA1c / ALT / mg）。纯标点、纯数字、百分比、空白、纯符号**不计入分母**。
4. 逐词判定达标：

> 一个计分词 w **达标** ⟺ 满足下列任一条：
> 1. w ∈ 计量单位白名单
> 2. w ∈ 常见健康词白名单
> 3. w 的全部汉字 ∈ 六年级字表 **且** w ∉ jargon 术语集

$$\text{达标率} = \frac{|\{w \in W' : w\ \text{达标}\}|}{|W'|}$$

**目标：strict 口径 ≥ 90%。** 等价表述：Dale–Chall 意义下的中文难词率 ≤ 10%。

判定为词级**微平均**（所有词拉通算一个比例），与 KPI 定义「转译后文本中符合小学六年级可读水平的**词汇比例**」字面一致。场景**宏平均**（每场景一个分再等权平均）作为诊断附报，两者不可混用。

## 2. 三个口径

| 口径 | 字级基准 | 说明 |
|---|---|---|
| **`strict`** | 课标**常用字表一 2500** | **主 KPI。医学实体不豁免** |
| `glossed` | 同上 | 术语后紧跟 ≤15 字白话括注即记达标 |
| `lenient` | 字表一+字表二 **3500** | 义务教育全程档（含初中），宽松诊断 |

> **命名说明**：票据初稿写的是 `strict / glossed / strict_2500` 三个口径，其中 `strict` 用 3500 字。实现时改为 **`strict` 用 2500**，因为 2500 才是课标明确指定的**第三学段（5–6 年级）评价依据**，而 3500 是义务教育全程（含初中）的量。项目 KPI 说的是「小学六年级可读水平」，用 2500 更贴字面也更经得起质疑；3500 保留为 `lenient` 诊断口径。

**医学实体为什么不豁免**：若把药名/病名/检查名从分母豁免，等于承认「术语无法回避」之后又对同一让步再次计价，且指标可被「堆术语」刷分。术语计为不达标，正是「术语密集原文得分低、转译后得分回升」这一区分度的来源。

**`glossed` 的定位**：它不是找补，是有据可依的备选。Dale–Chall 的难词率算的是「读者不认识的词」，一个已被白话解释的词不再是难词——「高血压（血压偏高）」老人是看懂了。若 strict 最终够不着 90%，切到 glossed 需在报告中显式披露，且两个口径的数并排给。

## 3. 词表：全部来自官方文件

**本指标不使用词频代理表。** 词表的权威性直接来自国家标准，这是它可辩护的根本。

| 词表文件 | 来源标准 | 规模 | 机读来源 |
|---|---|---|---|
| `grade6_chars.txt` | **《义务教育语文课程标准》(2022年版) 附录5 常用字表一** —— 课标指定为**第三学段(5–6年级)识字写字能力评价依据** | **2500**（实测精确命中） | [zispace/hanzi-chars](https://github.com/zispace/hanzi-chars) |
| `edu_ext_chars.txt` | 同标准 常用字表二 | **1000** | 同上 |
| `general_standard_L1.txt` | **《通用规范汉字表》(国务院 2013)** 一级字表（常用字集） | **3500** | 同上 |
| `hsk_words.txt` | **GF 0025-2021《国际中文教育中文水平等级标准》** 一~四级词 | 3148 | [elkmovie/hsk30](https://github.com/elkmovie/hsk30)（**MIT**） |
| `jargon.txt` | 七个爬虫库实体名字段收割（正式名列 + 别名列，别名中的口语说法已剔除） | 42,979 | 本项目自建 |
| `units_whitelist.txt` | 手工维护 | 73 | — |
| `health_common_whitelist.txt` | 手工维护 | 176 | — |

### 交叉核对（构建时自动执行）

`build_lexicon.py` 每次构建都会比对课标 3500（表一+表二）与《通用规范汉字表》一级字表 3500：

```
交集 3500，课标独有 0，通用规范独有 0
```

**两个独立颁布的国家标准字表完全一致。** 这不是巧合——《通用规范汉字表》文件头即声明「和《义务教育语文课程常用字表》一致」——但程序化核对把这条从"声称"变成了"已验证"，也构成对转写仓库转录质量的一次校验。

### 词表的已知局限（必须披露）

- **`hsk_words.txt` 的上游仓库自述为 OCR 提取、未充分校对**，词级层存在个别错漏的可能。
- **`jargon.txt` 由实体名字段收割**，可能漏收未在实体名中出现的术语，也可能误收个别日常词（已用 `health_common_whitelist` 救回一批）。它是本指标中**唯一非官方**的词表，也是最需要人工巡查的一份。
- **词表构建全程硬失败**：字表规模不符、两个国家标准交叉核对不一致、语料目录缺失、jargon 收割为空——任一情况直接非零退出且不覆盖现有词表。载入时另有一道 `check_integrity`。这是刻意的：这些故障都不会让程序崩，只会把 KPI 悄悄打高（实测语料缺失导致 jargon 为空时，区分度从 0.313 塌到 0.114，未转译原文被打到 ~0.9 并报告达标）。
- **`zispace/hanzi-chars` 仓库未声明开源许可**。本项目只取其中的国家标准字表内容（标准本身非该仓库创作），不分发其额外内容。
- 金标准 **《义务教育常用词表（草案）》**（教育部语信司组织、厦大苏新春团队、商务印书馆 2019，15,114 词，**三级 = 5–6 年级**）是国内唯一官方「词→年级」标准，但**无公开机读版**。当前实现是「官方字级 + 官方词级量表」的组合，尚不是词级年级标准本身。获取路径见 `docs/DATASETS_AND_BENCHMARKS.md` §3.1。

## 4. 实现要点

### 4.1 术语感知分词（关键设计）

**不能把分词结果直接拿去查 jargon。** `jargon.txt` 收的是完整实体名（"预激综合征"），而通用分词器会切成"预激"+"综合征"，两者都匹配不上——术语被系统性漏检。

实测代价：早期版本依赖 jieba 切分结果查表时，`预激综合征`、`肥厚型心肌病`、`内生肌酐清除率`、`尿素氮` 全部漏检，通俗/术语区分度只有 **0.199**，低于有效性门槛。

现行做法：先在**原文**上做最长匹配的术语跨度扫描（`_jargon_spans`，"心肌梗死"整体命中而非先命中"心肌"），jieba 只调一次，再按术语边界重切。修复后区分度回到 **0.29 以上**。

> 指标的判定结果不得取决于分词器恰好怎么切——那样指标既不可信也不可复现。

### 4.1b 别名列的口语过滤

七个库的**别名列**同时混着两类东西：正式同义词（"核磁共振检查"）与口语说法
（"拍片子""出汗"）。

两类都收，指标会**反向激励**：转译时加一句白话解释，反而因为解释里用了口语词
而多出一个不达标词——指标在惩罚它本该奖励的行为（实测 `做了核磁共振（一种拍片子）检查`
比 `做了核磁共振检查` 还低）。两类都不收，又会丢掉大量真术语（jargon 从 46,885
掉到 37,913，`核磁共振检查` 直接失去术语身份）。

现行做法是**分列收割再按判据剔除**：正式名列无条件进表；别名列中同时满足
「仅作为别名出现（从未作为正式名）」「长度 ≤4」「全部汉字都在六年级字表内」
三个条件的，判为口语说法剔除。实测剔除 3,887 条，`拍片子` 命中、`核磁共振检查`
因长度 6 不命中而保留。

剩余漏网的误报（"中毒""性病""出汗" 确实是实体正式名，但六年级读者无障碍）由
`health_common_whitelist` 修正——这正是该白名单存在的意义。

### 4.1c 括注按**位置**锚定

`glossed` 口径判断「某个词是否已被白话解释」时，锚定的是**字符偏移**，不是词面。

早期实现把括注前整段连续汉字及其**每一个后缀**登记为"已解释"：
`他得了慢性病（长期的病）` 会登记 `{慢性病, 性病, 病, …}`，于是文档**别处**一个
毫无解释的 `性病` 也被记达标。等于在文档任意位置加一个括注，就能给从未解释过的
术语放行。

改为位置锚定后，只有紧贴括注左侧的那个词会被救；同一术语出现两次而只有一次带
括注时，也只救带括注的那次。

同时，**救与不救和失败原因无关**（`jargon` 与 `char` 两类都救）。原实现只救
`jargon` 类失败，导致 `眩晕（头晕）` 被救而 `痉挛（抽筋）` 不被救——括注是否有效
不该取决于 `jargon.txt` 恰好收没收这个词，而该表自述不完整（见 §7）。

### 4.2 其他约定

- **日期掩码**只匹配**明确是日历日期**的形态：四位年份（19xx/20xx）、月+日、钟点。**刻意不匹配 `\d{2,4}年`** —— `高血压20年`、`病史15年` 是病程不是日期，吃掉它们会悄悄改变任何提到多年病史的文本的分母。剂量与疗程（`3个月`、`1日3次`、`7天`）同样保留。回归测试同时覆盖「不吃病程」与「仍吃真日期」两个方向。
- **含任何拉丁字母的词一律判 `latin`**，而不只是整词皆拉丁。否则 `CT检查` 通过而 `CT` 失败——同一个缩写是否计入 KPI 取决于分词器恰好有没有把它和后一个词粘起来，正是 §4.1 声明要杜绝的分词器依赖。
- **长度统计与打分同源**，都基于掩码后文本。否则日期时间被计入字数却未计入分母，「达标率与长度并排看」的两半算的是两段不同文本。
- **术语跨度扫描不设固定长度上限**，按表中实际存在的词长降序探测。早期硬编码 12 字，导致表中 876 条超长条目（最长 135 字）永远无法命中。
- **括注长度上限 15 字**：超过这个长度的括注本身就是另一段专业文本，不算把术语讲明白。
- **拉丁 token**（HbA1c / ALT / PSA）除单位白名单外一律不达标。
- **分词器回退**：jieba 不可用时回退正向最大匹配，结果中记 `segmenter` 字段以便追溯。

### 4.3 性能

1,000 字约 **10 ms**（单核）。早期按术语碎片逐段调 jieba 的实现是 394 ms/千字，改为单次调用后快约 40 倍。

## 5. 辅助指标（与达标率并排报告）

| 指标 | 依据 |
|---|---|
| **jargon 片段密度**（每 100 计分词的术语数） | [MedReadMe (EMNLP 2024)](https://aclanthology.org/2024.emnlp-main.958/) 证明：在传统可读性公式中**只加入 jargon 片段数量这一个特征**，就能显著提升与人工判断的相关性与稳定性 |
| 字数 / 句数 / 平均句长 | 平均句长是 Dale–Chall 及各中文可读性公式的第二自变量 |
| 转译/原文字数比 | 达标率是比例，扩充长度会机械稀释术语密度。**长度必须与达标率并排看**，只涨达标率不看长度的数不可采信 |

## 6. 对标依据（本指标不是自创）

| 对标 | 内容 |
|---|---|
| **Dale–Chall / DCRS** | 该公式的核心自变量就是「不在 3000 词熟词表内的**难词百分比**」，熟词表定义为"80% 以上四年级学生认识"。**DCRS 是 [BioLaySumm](https://biolaysumm.org/) 2023–2025 shared task 的官方可读性指标之一**。本指标即其中文六年级版：`1 − 达标率` = 中文难词率 |
| **AMA / NIH 六年级门槛** | 两家均建议患者教育材料**不超过六年级阅读水平**（[PMC 综述](https://pmc.ncbi.nlm.nih.gov/articles/PMC11262515/)）——直接回答「为什么是六年级」 |
| **BioLaySumm 三维框架** | Relevance / Readability / Factuality，各指标 min-max 归一化后维度内平均。本项目的「可读性 + 忠实性守门」是其简化 |
| **PLABA 人工 rubric** | simplicity / accuracy / completeness / brevity 四维（[TREC PLABA](https://bionlp.nlm.nih.gov/plaba2024/)），用作人工评价维度 |

## 7. 已知局限（诚实披露，写进对外材料）

学界对自动可读性指标有三条明确的负面结论，必须一并给出：

1. **[Lessons from TREC PLABA](https://arxiv.org/abs/2507.14096)**：自动的、基于参考的指标与人工判断**普遍相关性差**；且参赛模型在事实准确与完整性上接近人类，**但简洁性与简短性不行**。
2. **[Evaluating the Evaluators](https://arxiv.org/abs/2508.19221)**：通俗化摘要领域的 **8 个传统可读性指标都没有被人工判断验证过**；LM 作判官最好也仅 **Pearson 0.56**。
3. **[PlainMedScale](https://arxiv.org/abs/2608.01158)**（KONVENS 2026）：现有可读性指标**无法跨全部难度层级泛化**；LLM 即便被明确要求用通俗语言，输出**仍部分保留输入的复杂度**。

**本指标相对 FKGL / LENS / LM 判官的实质优势正在于此**：它**可解释、可审计、可逐词追溯**——每个不达标词都带失败原因（`jargon` / `char` / `latin`）并能列出来给人看（`--show-failures`）。这是刻意的设计取向，不是附加功能。

同时必须承认本指标做不到的事：

- 它只测**词汇**层面，不测句法复杂度、指代清晰度、信息组织。
- 它不测**忠实性**——可读性可以靠歪曲或删减原文换取，所以必须有独立的忠实性守门指标（见 ticket 08）。
- 词级微平均下同一文本内词高度相关，**置信区间极窄不等于结论极稳**；每 case 比率分布要另行报告。
- `jargon.txt` 是唯一非官方词表，其收割口径直接影响分数，属于本指标最大的主观项。

## 8. 用法

```bash
python3 pipeline/build_lexicon.py            # 构建词表（联网拉官方字表 + 读本地语料收 jargon）
python3 pipeline/build_lexicon.py --skip-jargon   # 只建字/词表，不读语料

python3 metrics/readability.py --selftest    # 自检：区分度 + 确定性 + 字表规模
python3 metrics/readability.py --text "……" --show-failures
python3 metrics/readability.py --text "……" --json
echo "……" | python3 metrics/readability.py

python3 -m pytest tests/ -q
```

**自检会在区分度 < 0.20 时直接失败**。这是刻意的硬门槛：没有区分度的可读性指标是坏指标，必须先修词表再用，不能带病上跑数。
