## 这一轮真跑最重要的发现

**可读性 97.4% 与忠实性 64.5% 的落差，是靠编造买来的。**

字数比中位 1.89、P90 4.72——模型在大幅扩长。

**⚠️ 一处必须更正的结论。** 判官只判完 200 题时，分档呈现出漂亮的单调剂量-反应
（最短档 38% → 最长档 68%），我据此报告了「原文越薄编造越多」的干净因果。
**全集 270 题判完后，单调性不成立：**

| 原文长度 | 忠实通过（200 题时） | **全集 270** |
|---|---|---|
| 40–165 字 | 38% | **51%** |
| 168–310 字 | 75% | 73% |
| 316–580 字 | 69% | 73% |
| 596–1196 字 | 68% | **62%** |

| 扩长比 | 全集忠实通过 |
|---|---|
| 0.3–1.2x | 69% |
| 1.2–1.9x | 64% |
| 1.9–2.9x | 76% |
| **2.9–15.6x** | **51%** |

**站得住的部分**：最短原文（51%）与最高扩长比（51%）确实是两个最差档，明显低于
其余的 62–76%。薄原文诱发编造这条成立。

**不成立的部分**：中间档并非单调过渡，且**最长原文档也掉到 62%**——那多半是另一种
机制（长原文覆盖不全导致漏项，而非编造）。把这说成"扩长比与忠实性单调负相关"是
过度解读部分样本。

教训：200/270 的部分样本虽然总体均值几乎没偏（64.5% vs 64.8%），**分档趋势却完全
可以是假的**。分层结论必须等全集。

**可读性与忠实性几乎不相关**：用药咨询可读性最高（0.969）而忠实性倒数第二（32%）；
运动与养生可读性最低（0.928）忠实性却有 67%。这正是两个指标必须并列的证据——
任何一个单独都不能代表质量。

**两种失败形态可以分开**：急症处置/检验报告解读是「不踩红线但漏要点」（忠实 90%+
而覆盖仅 64%）；饮食营养是「覆盖到了但踩红线」（覆盖 85% 而忠实 57%）。前者是保守，
后者是越界，对 verifier 是两类不同的判别目标。

**权益匹配 15/15 全挂**，是全集里唯一一个零通过的场景。

> **⚠️ 这条归因错了，已更正。** 我原先报成「模型把医保『否』说反」，判官也是这么判的。
> 但 fable-5 的判官审计、以及两个独立的教师标注 agent，各自发现了同一件事：
> **该类原文是没有字段名的裸 DB 行**——开头孤零零一个「否」，文本里没有任何线索
> 表明它指医保：
>
> ```
> 否
> 根据不同医院，收费标准不一致，市三甲医院约（5000——10000元）
> 药物治疗、支持性治疗
> ```
>
> 任何读者拿到这段都不可能知道「否」指什么。被测系统把它读成「不是这个病」
> 「不严重」「不传染」——**那不是转译失真，是输入缺陷**。这 15 题测的是 schema 猜谜。
>
> 已在 `extract_candidates.py` 加 `FIELD_LABELS`，多字段拼接时渲染成
> 「是否医保报销：否 / 大致费用：… / 治疗方式：…」。该类需重新抽取、重写、重判。

## 追加二：判官 rubric 校准——编造红线的"准确性例外"之争（2026-08-12）

延续追加一的复核，又对 `用药咨询`（31.6% 忠实，全场景最低）、`用药干预`（45.0%）
做了同样的人工抽样 + DeepSeek 交叉验证，起因是发现大量违规判定写着"编造原文没有的
XX 症状描述"——但这些症状描述往往医学上是准确的（比如低血糖症状"心慌出冷汗手抖"），
提出了一个问题：**判官该不该给"准确的超纲补充"网开一面？**

批量人工评审 + DeepSeek 独立盲评（不给判官结论）6+ 条典型案例后，答案是**不该**，
理由不是"从严保险"，是有实测反例：

- `用药干预-009`：患者吃伏格列波糖（α-葡萄糖苷酶抑制剂），原文原话写着「应充分注意
  由于本品糖吸收延迟作用的影响」——回答却编了「吃水果糖、喝糖水、吃饼干」急救低血糖，
  这几样对这类患者**起效严重迟缓或无效**（DeepSeek 独立核实并引《中国2型糖尿病防治
  指南》：此类患者低血糖必须用葡萄糖纠正，蔗糖/淀粉效果差）。
- 同一批复核里，另外 5 条编造的「吃点糖」对应的患者没吃这类药，那几条建议本身是对的。
- **行文长得一模一样，对不对完全取决于判官看不到的患者全药单**——这正是
  `metrics/judge_prompt.md` 里 A 级 criterion 2 那条设计理由（"左右互搏，不可复核"）
  想避免的事，只是之前没有一个实测案例把它钉死。

**结论：`metrics/judge_prompt.md` 的 A 级 criterion 2（无原文依据的用药/治疗/急救/
护理指令）维持"无论准确与否一律触红线"，并把这条写死、加了 `用药干预-009` 作为
实证案例（`live-003` 复核不是假设性论证）。** 同时补了一条容易漏判的点：症状描述
（B 级，可以）和处置指令（A 级，不可以）经常挤在同一句话里（"心慌手抖就要吃糖"），
必须拆开判，不能因为症状部分说得对就放过指令部分。

**对现有 270 题标签没有影响**：`用药咨询`/`用药干预`已判的"违规"里，凡是含编造
指令的案例，判官当时就已经正确判成 `any_violated: true`（即便判官笔记把症状描述
