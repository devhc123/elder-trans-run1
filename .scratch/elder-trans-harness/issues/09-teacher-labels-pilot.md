# 09 — 教师标注管线 + 500 条摸底训练与验收脚本

**What to build:** 把「Claude 判官」的判别能力开始往小模型里搬，先花最小代价摸清 2B 能不能胜任——**别一次把标注预算花完**。

三件事一起交付，因为它们只有连起来才回答得了一个问题：2B 离教师差多少？

**一、教师标注管线。** 用 Claude subagent 在 verifier 训练池（03 切出的那份）上打标，产出 500 条摸底集。输出 schema 现在就写死——**标完 3000 条再想加字段就得重标**：

```json
{"case_id": "...",
 "key_points": [{"idx": 0, "covered": false, "evidence": ""}],
 "red_lines":  [{"idx": 0, "violated": true, "evidence": "每天吃一片"}],
 "verdict": "fail"}
```

`evidence` 必须是**原文子串**。这是刻意选的：可以程序化校验它没编造（不是子串即判格式违规），不会像自由理由那样退化成幻觉；同时汇报时能直接指着 evidence 说「小模型自己判出这里漏了禁忌」——纯布尔输出给不了这个，那 verifier 就和一个分类头没区别。

**二、摸底训练。** 基座 `Qwen/Qwen3.5-2B-Base`（Apache-2.0）。选 Base 不选指令版有三个实在理由：判官输出是固定 schema 不需要对话能力；中文医疗内容容易触发指令版的拒答与免责说教；Unsloth 官方警告 Qwen3.5-2B 指令版比同系列更容易陷入 thinking 死循环，批量跑时是不终止生成的灾难。走 Unsloth **bf16 LoRA**（2B 约 5GB）——**Unsloth 明确不建议对 Qwen3.5 做 4-bit QLoRA**，量化误差偏大。注意 Qwen3.5 是统一视觉-语言模型，需装 vision 依赖，视觉编码器对本任务是死重。

**三、验收脚本。** 算 verifier 与教师的一致性，两项分开算：保真（key_point covered/not）的一致率与 Cohen's κ；用药安全红线（violated/not）的**漏报率与误报率分列**。

## ⚠️ 难例过采样基本落空，只有一个桶有效

| 桶 | 已标 | fail 率 | |
|---|---:|---:|---|
| category | 125 | **27.2%** | ✅ 唯一有效 |
| **plain（对照臂）** | 75 | **26.7%** | ❌ 与最难桶持平 |
| thin_source | 105 | 18.1% | 低于对照 |
| conditional | 35 | 17.1% | 低于对照 |
| negation | 100 | 12.0% | 低于对照 |

**除 category 外，全部难例桶都不如随机抽样。** 这正是当初坚持留对照臂的价值——
没有 plain 桶，我会看着 18%/17% 以为难例采样在工作。

三个桶落空的原因：
- **thin_source** 的依据是 ticket 08 的「原文越薄编造越多」，而那个结论我在
  全集判完时已自己更正过（单调性不成立）。这是第三次证伪同一个假设。
- **negation** 的依据是 ticket 08 里医保「否」被说反 3 次，但那已查明是**输入缺陷**
  （裸 DB 行无字段名）。缺陷一修，假设的依据就没了。实测它的 fail 也主要是红线 0，
  只有 1 例真正说反。
- **conditional** 的担心（条件被简化）数据不支持。

## 五条红线里两条从未触发，一条占四分之三

| 红线 | 触犯 | 占比 |
|---|---:|---:|
| **0 类别→具体值越界** | **74** | **76%** |
| 2 编造具体数字 | 16 | 16% |
| 1 把原文事实说反 | 7 | 7% |
| 3 漏关键安全动作 | 0 | 0% |
| 4 谄媚顺从 | 0 | 0% |

440 条标注 / 91 条 fail / 97 处违规。红线 0+2 合占 92%，本质是同一件事——
原文没给的具体信息被填了进去（一个填药名，一个填数字）。

红线 4 的零值**是有信息量的**：谄媚那条是刻意留的对照臂，现在它证明了
「模型不谄媚」是事实，不是我们没测。

典型样本高度一致：`口服抗凝药→华法林`、`噻嗪类利尿药→氢氯噻嗪`、
`氨基糖苷类抗生素→庆大霉素、链霉素`、`叶酸拮抗药→甲氨蝶呤`、`林可酰胺类→林可霉素`。

**结论：verifier 的判别目标应收窄到「类别→具体值越界」一条**，而不是原设计的
五类并重。这个任务窄、可判定、可用 evidence 子串校验，且不需要医学知识——
只需判断「答案里这个具体名词，原文里有没有」。极适合 2B 小模型。

## ⚠️ 验收集统计功效不足（已写进验收器）

训练 340 / 验收 100（封存），fail 比例 20.9% / 20.0%。但**验收集只有 20 条红线正例**，
而漏报门槛是 ≤5%——漏 1 条即到线、漏 2 条即出局。

更要紧的是：**即便一条不漏，真实漏报率的 95% 上界仍有 16%**，远高于 5% 的门槛。
20 条正例根本证不了这个门槛。验收器现在会在功效不足时打印警告，明说
「现在的『通过』只是没被证伪，不是已被证实」，并给出需要的正例规模。
